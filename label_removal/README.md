# [파트 4] 라벨 제거 이미지 생성

## 역할
편차 이미지에서 라벨 박스·지시선·제목 글자를 지우고 히트맵만 남긴다.
지운 자리는 주변 색으로 메운다(인페인팅).

## 입력
- `data/intermediate/deviation_map.png`

## 출력
- `data/intermediate/clean_deviation_map.png`

## 요구 사항
- 원본과 **같은 해상도**를 유지할 것. 파트 2·3이 좌표를 그대로 쓴다.
- 컬러바는 지우지 말 것. 파트 2가 색상 보정에 사용한다.
- 보안상 로컬 구동 모델만 사용 (회의 결정).

## 파트 2와의 연계
이 파일이 생기면 파트 2가 자동으로 우선 사용한다.
그때는 `--no-annotation-mask` 로 자체 라벨 제거를 꺼도 된다.
