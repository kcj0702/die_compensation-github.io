# +/- 보정영역 전환 경계 검토

기존 엔진은 수정하지 않는 검토용 결과입니다. 보정영역의 내부 중심선은 계산하거나 표시하지 않습니다.

1. `results_correction_only_3pct`의 최종 양(+)·음(-) 보정영역을 입력으로 사용합니다.
2. 두 보정영역에 속하지 않는 파트 내부 빈 공간에서, 서로 다른 최종 보정 연결영역까지의 거리가 같은 픽셀을 추출합니다.
3. 영역쌍은 `+/-`뿐 아니라 서로 분리된 `+/+`, `-/-`도 포함합니다. 따라서 선은 항상 두 보정영역 사이에만 있고, 한 보정영역 내부를 가로지르지 않습니다.
4. 기존 `zero_line_detection.zero_boundary.find_boundary_anchors`의 외곽 부호전환 앵커를 그대로 구합니다.
5. `+/-` 전환 경계는 앵커에서 70px 이내인 연결성분만 남깁니다. `+/+`, `-/-` 경계는 최종 보정영역끼리의 분할선이므로 앵커와 관계없이 남깁니다.

`results_correction_sign_boundaries`의 검토 보드:

- 1: 최종 양·음 보정영역
- 2: 기존 엔진의 외곽 부호전환 시작 앵커
- 3: 전체 등거리 경계 후보 (회색 `+/-`, 자홍 `+/+`, 청록 `-/-`)
- 4: 최종 분할선 (노랑은 시작 앵커와 연결된 `+/-`)
