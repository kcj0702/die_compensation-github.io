# 근접영역 병합 + 4% 제로라인 판정

기존 엔진과 분리된 세 번째 판정용 실험입니다.

## 적용 규칙

1. 회색 미측정면은 `+3.01 mm`로 처리합니다.
2. 양 보정은 `> +0.5 mm`, 음 보정은 `< -0.5 mm`입니다.
3. 같은 부호의 보정영역 사이 간격이 최대 `24 px`이면 하나의 큰 보정영역으로 병합합니다.
4. `-0.5 ~ +0.5 mm` 중 양·음 보정영역 모두에 인접한 영역을 제로라인 후보로 봅니다.
5. 제로라인 후보는 실제로 연결된 중립 영역별로 면적을 계산합니다. 보정영역에 적용한 거리 병합은 제로라인 후보에는 적용하지 않습니다.
6. 연결영역 면적이 전체 파트의 `4% 이상`이면 최종 제로라인 영역으로 채택합니다.
7. 병합된 보정 연결영역의 내부 구멍 중 최종 제로라인이 하나도 없는 경우에만 해당 구멍을 채워 표시합니다.

구멍 채움은 표시용 보정 마스크에만 반영하며, 편차 임계값 원본 마스크와 최종 제로라인 면적 계산에는 넣지 않습니다.

## 결과 색상

- 빨강/파랑: 병합된 양/음 보정영역
- 밝은 주황/하늘: 최종 제로라인이 없어 채운 양/음 보정영역 내부 구멍
- 초록/노랑: 최종 제로라인 영역과 경계

## 실행

```powershell
& .venv\Scripts\python.exe `
  mold-correction-demo\experiments\zero_line_area_edge_preview\generate_merged_4pct_preview.py
```

결과는 `results_merged_correction_4pct` 폴더에 저장됩니다.
