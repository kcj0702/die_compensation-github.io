# 편차값·포인트 좌표 추출 계약

이 문서는 `deviation_extraction` 1차 데모의 입출력 범위를 정의한다.

## 입력

| 항목 | 필수 | 계약 |
|---|---:|---|
| 편차 맵 | 예 | OpenCV가 읽을 수 있는 컬러 이미지 |
| 제로 라인 마스크 | 아니요 | 0은 배경, 0보다 큰 값은 전경 |
| 컬러바 ROI | 아니요 | 원본 이미지 기준 `(x, y, width, height)` |

편차 맵에는 가로형 숫자 라벨과 파란 지시선이 있어야 한다. 입력 이미지는 외부 서비스로 전송하지
않으며, `--offline` 사용 시 모델도 로컬 파일에서만 읽는다.

## 좌표

- 원점은 이미지 좌상단이다.
- `x`는 오른쪽, `y`는 아래쪽으로 증가한다.
- 픽셀 좌표는 `(x, y)`, 배열 접근은 `[y, x]` 순서다.
- 정규화 좌표는 `x / width`, `y / height`이며 소수 넷째 자리로 반올림한다.
- 지시선을 찾지 못한 행은 좌표와 정규화 좌표를 빈 값으로 저장한다.

## CSV 출력

CSV는 UTF-8 BOM 인코딩으로 저장하며 검출 결과가 없어도 헤더를 유지한다.

| 컬럼 | 형식 | 의미 |
|---|---|---|
| `point_id` | 문자열 | 실행 내 라벨 정렬 ID |
| `x_px`, `y_px` | 정수 또는 빈 값 | 지시선 끝점의 원본 픽셀 좌표 |
| `x_norm`, `y_norm` | 실수 또는 빈 값 | 이미지 크기로 정규화한 좌표 |
| `value_mm` | 실수 또는 빈 값 | 라벨에서 판독한 편차값 |
| `label_color` | `red` 또는 `white` | 라벨 내부 색상 분류 |
| `in_zero_line` | `True` 또는 `False` | 마스크의 해당 좌표가 전경인지 여부 |
| `confidence` | 상태 문자열 | 검토가 필요한 원인 |

`confidence`는 확률이 아니다. 정상은 `ok`이며 문제는 다음 코드를 `|`로 연결한다.

- `value_not_read`
- `leader_line_not_traced`
- `color_mismatch`

## 디버그 이미지

`--debug`를 사용하면 라벨 박스, 연결선, 끝점, 판독값을 원본 위에 표시한다. 정상은 초록색,
검토가 필요한 결과는 빨간색이다. 저장 경로는 `--debug-out`으로 지정한다.

## 종료 상태

- 라벨을 한 개 이상 처리하면 종료 코드 0을 반환한다.
- 라벨을 찾지 못하면 빈 CSV를 저장하고 종료 코드 2를 반환한다.
- 입력, 모델 또는 출력 파일 오류는 0이 아닌 코드로 종료한다.
