# point_selection

검출된 편차 포인트 중 보정시트에 올릴 것만 고른다. 좌표를 옮기거나 값을 바꾸지 않고
"어떤 것을 기본으로 켤지"만 정한다. 나머지 포인트는 지우지 않으므로 화면에서 언제든
다시 켤 수 있다.

## 왜 필요한가

스캐너는 라벨을 수십~수백 개 찍지만, 실제 보정시트에는 15개 안팎만 들어간다.
실측 3개 품번의 검출 수는 79 / 130 / 40개였고 예시 시트의 표기는 15개였다.

## 무엇을 고르는가

| 이유 | 기준 |
|---|---|
| `peak` | 이웃들 사이에서 signed 값이 국소 극값. 스프링백이 가장 큰 지점이다 |
| `sign_change` | 이웃과 부호가 반대. 제로 라인이 지나는 자리다 |
| `extreme` | 전체 최대·최소. 금형 보정의 기준점이라 항상 남긴다 |

이웃은 스캔 픽셀 좌표에서 찾는다. 이미지 대비 %는 가로와 세로의 실제 길이가 달라
등방적이지 않다(1306×680 스캔에서 1%는 가로 13px, 세로 6.8px).

## 두 가지 함정

**부호 변화는 그대로 두면 절반이 걸린다.** 편차장은 0 근처에서 계속 진동해서,
"이웃 중 부호가 다른 것이 있으면 선택"으로 잡으면 실측에서 전체의 40~55%가 뽑혔다.
그래서 양쪽 모두 `SIGN_MIN_ABS_MM`을 넘어야 인정한다.

**제로 크로싱은 점이 아니라 선이다.** 그 선을 따라 후보가 무더기로 나오므로,
`SIGN_MERGE_RADIUS_RATIO` 안의 후보는 하나로 묶고 |편차|가 가장 큰 것만 남긴다.

두 처리를 적용한 실측 결과는 다음과 같다.

| 품번 | 전체 | 선별 | 피크 | 부호변화 | 최대최소 |
|---|---:|---:|---:|---:|---:|
| 64XX2 | 79 | 19 | 13 | 10 | 2 |
| 67XX6 | 130 | 34 | 19 | 20 | 2 |
| 71XX2 | 40 | 10 | 5 | 4 | 2 |

이유는 겹칠 수 있어 합이 선별 수보다 크다.

## 사용

```python
from point_selection import select_key_points

selection = select_key_points(points)   # dict 또는 xPx/yPx/value 속성을 가진 객체
selection.ids                            # 선택된 포인트 id
selection.to_dict()                      # UI 응답용 요약
```

기준값은 모두 인자로 덮어쓸 수 있고 기본값은 `config.py`에 있다.

## 현재 제약

- 사람이 고른 시트를 재현하지는 않는다. 예시 시트의 15개는 대체로 균일한 음수 값으로,
  극값이나 부호 변화라는 기준과는 다른 판단이었다. 이건 출발점이고 최종 선택은 사람이 한다.
- 판독값이 틀리면 그대로 따라간다. 극값을 항상 남기므로 오판독이 오히려 뽑히기 쉽다.
  실제로 67XX6에서 +9.0mm가 여러 점에 나타나는데 컬러바 범위를 보면 오판독으로 보인다.
- 기준값은 3개 품번으로만 맞췄다.
