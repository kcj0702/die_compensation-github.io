# [파트 5] 파트 이미지 깊이 측정

## 역할
단일 RGB 이미지에서 깊이를 추정해 형상 특징(필릿, 단차 등)을 파악한다.
멘토가 형상 특징이 보정량에 영향을 준다고 언급한 데 따른 탐색 과제다.

## 입력
- 파트 정면도 이미지

## 출력 — `data/intermediate/depth_measurements.csv`
| 컬럼 | 설명 |
|---|---|
| `point_id` | 파트 3의 `point_id` 와 대응 |
| `x`, `y` | 픽셀 좌표 |
| `depth_rel` | 상대 깊이 0~1 |
| `curvature` | 국소 곡률 추정값 |
| `feature` | 형상 분류 (flat / fillet / step / hole) |

## 검토 대상
- Depth Anything 계열 단안 깊이 추정 모델 (HuggingFace)
- 스테레오 방식 (카메라 2대)

## 주의
회의에서 **데모와는 별개의 탐색 과제**로 분리하기로 했다.
일요일 데모에 필수는 아니다.
